# Yuxiang Zhao · Research homepage

Live site: <https://zhaoyx239.github.io/>

The homepage is a static GitHub Pages site. `index.html` contains the selected projects, full publication list, and short biography; `styles.css` controls the responsive layout. No build step is required.

To preview changes locally, run `python3 -m http.server 8000` from the repository root and open `http://localhost:8000/`. Keep project entries focused on contributions; put citations in Papers.

The optional Shields.io badges fetch public GitHub star counts and Hugging Face model downloads over the last 30 days. Counts refresh according to the services' caches and are not stored in this repository.
