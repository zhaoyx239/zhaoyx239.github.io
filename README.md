# Yuxiang Zhao · Research homepage

Live site: <https://zhaoyx239.github.io/>

The homepage is a static GitHub Pages site. `index.html` contains the project descriptions, publication records, and short biography; `styles.css` controls the responsive layout. No build step or external assets are required.

To preview changes locally, run `python3 -m http.server 8000` from the repository root and open `http://localhost:8000/`. When adding a project with a paper, link the project card to its corresponding entry in the Papers section.
